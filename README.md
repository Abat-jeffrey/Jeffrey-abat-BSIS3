# ISPSC FindIt (Lost and Found Web System)

## Stack
- PHP (PDO)
- MySQL (XAMPP)
- HTML/CSS/JS
- Chart.js

## Folder Structure
- `/auth`
- `/dashboard`
- `/chat`
- `/items`
- `/reports`
- `/includes`
- `/assets`
- `/database/ispsc_findit.sql`

## Setup (XAMPP localhost)
1. Copy project to `htdocs/Jeffrey-abat-BSIS3`.
2. Start Apache + MySQL in XAMPP.
3. Import `database/ispsc_findit.sql` in phpMyAdmin.
4. Open `http://localhost/Jeffrey-abat-BSIS3/auth/login.php`.

## Default Accounts
